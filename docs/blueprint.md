# **App Name**: LoanPilot

## Core Features:

- Loan Capacity Calculation: Calculate loan eligibility and suggest an appropriate loan amount based on income, debt, and credit history using AI tool.
- Fraud Detection: Detect fraudulent loan applications using AI algorithms, identifying inconsistencies in provided documents and financial claims.
- Guided Submission Alerts: Provide real-time alerts for missing or inconsistent information during the loan application process using an AI tool.
- Loan Application Form: Interactive loan application form with fields for income, debt, credit history, and other relevant information.
- Loan Score Display: Visually present the loan eligibility score and recommended amount in a clear, understandable format.
- Corrective Action Suggestions: Suggest specific corrective actions to help applicants improve the accuracy of their applications and reduce rejection risk.

## Style Guidelines:

- Primary color: Soft blue (#7EC4CF) to evoke trust and reliability.
- Background color: Very light blue (#EAF6F8), almost white, to keep things airy and non-distracting.
- Accent color: Warm coral (#F26419) for CTAs and important alerts.
- Headline font: 'Poppins', a geometric sans-serif font with a precise, contemporary feel.
- Body font: 'PT Sans', a humanist sans-serif offering both modernity and warmth, making information accessible.
- Use clear and professional icons to represent different data points and actions.
- Design a clean and intuitive layout that guides users through the application process.
- Use subtle animations to highlight key information and provide feedback.
